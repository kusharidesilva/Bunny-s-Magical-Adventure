# Asset Manifest

All visual and audio material is original. The illustrations are stored locally as SVG assets, with gameplay textures and audio generated by project code. The production build does not load images, fonts, music, or sounds from third-party URLs.

The SVG illustrations and vector textures share a consistent storybook palette. The bunny's visible sprite animates separately from its fixed physics body so decorative motion does not change collision boundaries.
